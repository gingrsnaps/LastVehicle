Optional audio rebuild: use Python with NumPy plus FFmpeg/ffprobe on PATH, then run `python prepare-audio.py`. The script downloads the original CC0 music/metal-wood pack and creates the seven processed recordings next to itself. It is not run by the game. The wet and creature footsteps were separately downmixed to mono 32 kHz Vorbis quality 4 with a 3 ms onset fade and gain toward -9 dBFS; their exact source archive, original member and gain are in dist/assets/assets-manifest.json and docs/footstep-audio-inspection.json. Rebuilding assets requires internet access; playing the local game does not.
